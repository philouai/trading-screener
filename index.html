What this screener does

Identifies stocks showing the same setup that preceded Birkenstock's 17% snap-back in May 2026: a fundamentally strong business trading near multi-year lows, with a buyback signal and an imminent catalyst.

The 7 criteria (ordered hardest → easiest)

  • High short interest (>5% float) — the amplifier. When a catalyst hits, shorts are forced to cover, magnifying the move. Rarest criterion in the S&P 500.
  • Buyback signal — share count declining YoY. Management putting capital behind the thesis. Second rarest.
  • P/FCF below 5yr average — forward P/E meaningfully below trailing 5yr norm. Compressed valuation is the core setup condition.
  • Revenue still growing — separates a recoverable dip from a value trap. Positive YoY revenue growth required.
  • Strong fundamentals — positive operating cash flow + profit margin >5%. Business must still work.
  • Earnings within 30 days — the timing catalyst. Without a defined event horizon, a compressed stock can stay compressed indefinitely.
  • Near 52-week low — entry point. Within 20% of the 52-week low.

Waterfall engine

Criteria are applied in order from hardest (fewest stocks pass) to easiest. After each criterion, the pool shrinks. This means instead of 503 × 7 = 3,521 API calls, a typical scan takes roughly 800–1,200 calls — 3× faster.

Delta scan

Once a full scan is cached, the "Re-scan: new stocks only" button checks only the stocks that didn't previously pass criterion 1 (high short interest). Any that now pass are run through the full waterfall. This catches new entries in seconds.

Data source

Yahoo Finance via allorigins CORS proxy. No API key required — works on GitHub Pages. Data may be delayed 15 minutes for some fields. Short interest is typically updated twice monthly by FINRA.

European markets

Toggle to EU mode for Euro Stoxx 600 representative coverage (~170 stocks from major exchanges). Tickers use Yahoo's suffix notation: .AS (Amsterdam), .DE (Frankfurt/Xetra), .PA (Paris), .L (London), .SW (Zurich), .MI (Milan), .MC (Madrid).

Technical layer

This is the fundamentals screener. A technical criteria layer (RSI, MACD, volume patterns) will be added as a second tab — pass the technical criteria to the developer and they will be integrated.
